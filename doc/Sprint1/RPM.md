User stories planning to execute:
	1. Generate monthly expense reports
	2. Automate subscriptions by the user itself
	3. Transfer the money
	4. Monitor credit score



Inspirations for user stories:
	1. Monthly expense reports
	-> Normal bank statements
	
	2. Automate subscription by the user itself
	-> Current auto-renewal, doesn't have an end date to stop the payments. Thus let's implement the start and end date for the user to select, if needed.

	3. Transfer the money
	-> Transfer the money using only the banking software environment, instead of using third-party services such as Interac, thus implementing your own bank transfer, which would be at no cost to the users.

	4. Monitor credit score
	-> Some banks have complex ways to check our own credit score. But this feature would enable our users to view their credit score easily through the bank web app itself.

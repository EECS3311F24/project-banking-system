# Banking System

## Motivation
This project aims to provide a modern, user-friendly banking solution tailored to the specific needs of different users, such as young professionals, small business owners, and students. By addressing gaps in traditional banking, it simplifies financial management with features like real-time alerts, bill splitting, and credit score tracking, empowering users to achieve their financial goals efficiently.

## Project Description
This project aims to simplify financial management by creating a user-friendly banking application with personalized features like real-time fraud alerts, bill splitting, and multi-currency support—that address the specific needs of modern users overlooked by traditional banks.

## Installation
To develop on this project, you currently need the following:
- NodeJS (installation of other dependencies)
- Angular CLI
- Java 23
- IntelliJ
- VSCode

First, clone the repository.

To run the backend:
- Open IntelliJ with the path folder backend/bankApp
- To run the backend, run the <code>BankAppApplication.java</code>

To run the frontend:
- Open VScode with path folder frontend
- Run <code>npm install</code> in the terminal
- Run <code>ng serve</code> in the terminal
